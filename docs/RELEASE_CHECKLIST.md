# Checklist obligatorio antes de entregar una versión

- [ ] `manifest.json` existe en la raíz de la carpeta entregada.
- [ ] El número de versión coincide entre manifiesto, README y documentación.
- [ ] La extensión carga mediante **Load unpacked**.
- [ ] **Extraer contenido** funciona en una página HTTPS real.
- [ ] Si Chrome solicita acceso a sitios web, aceptar el permiso permite continuar.
- [ ] El selector visual abre y mantiene la selección.
- [ ] El análisis de metadatos responde.
- [ ] La descarga ZIP responde.
- [ ] No existe interfaz ni lógica activa de Google Drive.
- [ ] No se requiere desactivar Microsoft Defender.
- [ ] README.md representa el sistema vigente.
- [ ] `docs/CURRENT_STATE.md` y `docs/BUG_HISTORY.md` están actualizados.
- [ ] La versión anterior se conserva para auditoría; no se sobrescribe silenciosamente.
